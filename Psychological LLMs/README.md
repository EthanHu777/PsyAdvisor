## 🔓 Small-scale Open-source LLMs
**Compact & transparent models** 🔍  
Lightweight yet efficient models perfect for customization and research:
- **GLM4-9B-Chat** 🦉 *9B parameter variant of GLM-4*  
- **Qwen2.5-7B-Instruct** 🎯 *7B instruction-tuned model by Alibaba*  
- **Llama3.1-8B-Instruct** 🦙 *Meta's 8B fine-tuned version*

- **SoulChat2.0** 🔄 *Enhanced version with multi-turn dialogue*
